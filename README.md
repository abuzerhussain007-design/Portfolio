## GitHub Pages par live karne ka tareeqa

1. GitHub par naya repository banayein (misal: `portfolio`), "Public" select karein.
2. `index.html` file upload karein → "Commit changes".
3. Repository ke **Settings** → **Pages** mein jayein.
4. Branch: `main`, folder `/ (root)` select karke **Save** dabayein.
5. 1-2 minute baad live: `https://<aapka-username>.github.io/<repo-naam>/`
